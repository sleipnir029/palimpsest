# T01 — pixi init + lockfile

## Why
Establish a reproducible environment that installs cleanly on macOS arm64. This is the foundation; if T01 fails, nothing else works. This task is the solution to the v1 dependency hell root cause (docling on M1).

## Input state
- Repo contains only: `README.md`, `SETUP.md`, `CLAUDE.md`, `EXECUTION.md`, `palimpsest-v2-design.md`, `PROGRESS.md`, `DEVIATIONS.md`, `tasks/`, and empty top-level directories.
- `pixi --version` works.
- `.env` exists with at least `ANTHROPIC_API_KEY=...`.
- Git is initialized and the initial commit is in place.

## Output state
- File `pixi.toml` exists with these sections:
  - `[workspace]`: `name = "palimpsest"`, `channels = ["conda-forge"]`, `platforms = ["osx-arm64", "linux-64"]`
  - `[dependencies]`: `python = "3.11.*"`, `sqlite`, `pymupdf`, `pymupdf4llm`
  - `[pypi-dependencies]`: `anthropic`, `pyoxigraph >= 0.5.8`, `rdflib`, `pyshacl`, `linkml`, `linkml-runtime`, `marimo`, `textual`, `rich`, `typer`, `fastapi`, `uvicorn`, `dulwich`, `httpx`, `pydantic >= 2`, `python-dotenv`
  - `[tasks]`: `test = "pytest -v"`
- File `pixi.lock` exists (generated by `pixi install`).
- File `pyproject.toml` exists with `[project]` having `name = "palimpsest"`, `version = "0.1.0"`, and `[tool.setuptools.packages.find] where = ["src"]`.
- File `src/palimpsest/__init__.py` exists with one line: `"""palimpsest."""`.
- File `.gitignore` exists and includes `.env`, `.pixi/`, `__pycache__/`, `*.pyc`, `palimpsest.db`, `cache/`, `store/`, `notebooks/__marimo__/`.

## Verification
```bash
pixi install
pixi run python -c "import palimpsest; print('ok')"
```
First command must exit 0 (downloads packages). Second must print exactly `ok`.

## Will touch
- `pixi.toml` (new)
- `pixi.lock` (new — generated by `pixi install`)
- `pyproject.toml` (new)
- `src/palimpsest/__init__.py` (new)
- `.gitignore` (new or edit)

## Will NOT touch
- `CLAUDE.md`, `EXECUTION.md`, `palimpsest-v2-design.md`, `README.md`, `SETUP.md`, `PROGRESS.md`
- `DEVIATIONS.md` is exempt: append a log entry when a deviation occurs (per the file's own header), but make no other edits.
- Any file in `tasks/`
- Any file in `papers/`, `schema/`, `skills/`, `docker/`, `notebooks/`, `tests/`, `queries/`, `experiments/`, `thesis/`
- Any source file under `src/palimpsest/` other than `__init__.py`

## Out of scope
- Adding GPU-side dependencies (docling, MinerU, olmOCR, Chandra) — those go in the `palimpsest-gpu` Docker image (T10–T13), not in pixi.toml.
- Setting up the agent loop → T06.
- Cost meter, providers, anything functional → later tasks.

## Notes / references
- Pixi docs: https://pixi.sh/dev/
- Design ref: §F6 of palimpsest-v2-design.md.
- If a package fails to install on M1, do NOT switch it to pip-only without checking conda-forge first. If conda-forge has no arm64 build, add to `pypi-dependencies` and document why in `DEVIATIONS.md`.
- Do NOT add `pytorch`, `transformers`, `torch`, or anything ML-heavy to pixi.toml. Those live in the GPU Docker image only.
- `pixi.lock` is a binary blob — commit it but do not edit it by hand.
